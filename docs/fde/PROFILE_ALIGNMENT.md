# FDE and staff-level competency map

This project was scoped using the portfolio owner's supplied resume: LangGraph orchestration, backend APIs, enterprise agent controls, AWS/Azure delivery, model evaluation, data integration, production RCA and customer-facing implementation. Those are resume-derived background statements, not accomplishments established by ASTERION.

| Existing experience theme | Repository demonstration | Boundary |
|---|---|---|
| Agent orchestration / human checkpoints | Shared nodes and native LangGraph adapter | Optional framework execution must be validated separately |
| Backend API / governance | Typed requests, tenant principal, role gate, idempotency | Local auth is not enterprise SSO |
| Model evaluation / grounding | Input-oracle separation, witnesses, counterexamples | No live model-quality benchmark |
| Integration and delivery | Synthetic CRM/ERP failure semantics, acceptance workbook | No real customer connector |
| AWS/Azure architecture | Delivery/identity/storage topology and AWS foundation | No cloud deployment claim |
| RCA and client ownership | Failure report, runbook, RACI, exact handoff evidence | No production incident or customer adoption claimed |
| Technical leadership | ADRs, trade-offs, excluded scope, next experiment | The owner must review and explain the generated code |

No private resume, contact details, employer code or client data is redistributed. A future resume bullet should accurately name the implemented slice and actual validation, not describe this artifact as a production customer deployment.
