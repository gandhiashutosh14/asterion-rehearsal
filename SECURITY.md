# Security policy

ASTERION is an experimental local prototype and is not supported for public internet exposure or production customer data. The [threat model](docs/THREAT_MODEL.md) records its trust assumptions and unimplemented controls. The default reference workflow has no network or production-write tool.

Do not commit tokens, cloud credentials, customer fixtures or private reports. Use private repository security reporting if enabled; otherwise contact the owner through their public GitHub contact route with a non-sensitive summary. No security response SLA or compliance certification is offered.
