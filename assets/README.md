# Visual asset provenance

The canonical diagrams and hero are original vector layouts generated by `scripts/render_diagrams.py`. SVGs preserve editable text, boxes and connectors. PNGs are raster exports of those SVGs. Font files are not included; the renderer expects DejaVu Sans at the documented system path, which can be changed to a locally installed font.

Screenshots are actual Playwright captures of `site/index.html` and the generated HTML report. They are not a depiction of a running AWS/Azure console. The diagrams distinguish local implementation, optional integration and target architecture.

Do not add “production ready,” vendor certification logos, customer logos or invented metrics to these assets. Change diagrams when the implementation boundary changes. The included case-study figures are drawn from the measured synthetic report, not forecasts.

`rehearsal-walkthrough.gif` cycles through actual browser captures of three selected stored result views. It is a presentation animation, not a recording of live agent execution.
